## 5. 옛 기법이 2026년 모델에도 통하는가 — 비판적 검토

기준: 어느 시점·어느 모델에서 검증된 기법인지, 지금(Qwen3.5/3.8, Qwen3-VL-32B, InternVL3.5 시대)에도 같은 이유가 살아 있는지.

| 기법 | 검증된 시점·모델 | 지금도 유효한 이유 / 무효한 이유 | 판정 |
|---|---|---|---|
| **a/b/c/d 토큰 로짓 채점(생성 대신)** | 2026-08 16기 1·2위(Qwen3.5-27B, Qwen3-VL-8B/32B), 2025-02 Osaka(Qwen2.5-32B) | 모델 세대와 무관한 구조적 이점: 파싱 오류 0, 확률이 나와 TTA·앙상블·불확실도 계산 가능. 최신 모델은 지시 준수가 좋아 파싱 문제 자체는 줄었지만, 확률이 필요하다는 이유가 남음. thinking 기본 ON인 Qwen3.8은 `enable_thinking=False`로 끄고 채점 | **채택** |
| **보기 순서 셔플 학습 + 순열 TTA** | 2026-08 2위 +1.5%p(8B), 1위도 기본 채택(27B), Osaka 1위, LLM Science Exam 1위(Llama-2 시절, 120순열도 불안정) | 위치 편향은 최신 LLM에도 남아 있으나 모델이 클수록 줄어듦. 27B에서의 순수 이득은 미측정(1위는 ablation 없음). 비용은 추론 4배. 텍스트 VQA는 보기가 근사 문자열이라 위치 편향보다 철자 대조가 관건일 수 있음 | **채택하되 축소**: 기본 TTA2, 불확실 문항만 TTA4. 검증에서 TTA1 대비 이득이 √D 문턱 미만이면 TTA2로 고정 |

| **해상도(visual token) 상향** | 2위 +4.75%p(720×960 원본, 원본 이상은 무효), 1위 불확실 문항 1536 | 최신 모델도 픽셀 수에 비례해 토큰을 쓰므로 "기본값이 원본보다 작게 줄이는가"는 여전히 첫 확인 사항. 단 2위의 "원본 이상 무효"는 **개수 세기** 결론. 작은 글자는 원본 이상으로 키우면 글자당 토큰 수가 늘어 읽기가 나아질 수 있어 텍스트 VQA에서는 재검증 필요 | **채택 + 재검증**: 원본 / 1.5배 / 2배 토큰을 검증셋 층·상호·숫자 유형별로 비교 |
| **계열이 다른 모델 로그확률 앙상블** | 2위 +26문항(Qwen2.5-VL-7B), +17문항(Qwen3-VL-32B); LAVA 2024 1·3위 투표 앙상블(Qwen2-VL); LLM Science Exam 6모델 | 이득의 원천(오류 상관)은 세대와 무관. 다만 2026년엔 주력이 워낙 강해 **한 세대 전 모델은 −1%p 이내 조건을 못 넘길 수 있음**. 후보를 최신 세대(Qwen3-VL-32B, Qwen3.8-27B, InternVL3.5, Gemma 4)로 잡고 불일치율 ≥ 8%로 걸러야 함. 같은 Qwen 계열끼리는 불일치가 낮을 수 있으니 타 벤더 1개 포함 | **채택**(멤버 선정 기준을 그대로 적용) |
| **질문 유형별 가중치** | 2위 +5문항 | 유형 판별이 가능하면 유효. 텍스트 VQA는 층/상호/전화/가격/시간처럼 유형이 더 명확해 오히려 적용하기 쉬움 | **채택** |
| **불확실 문항만 선택적 재추론·결합** (hires, LoRA OFF, multi-crop) | 1위 +0.002(Public), 15기 1위 count 재추론 | 방법론은 건전하나 1위의 이득은 노이즈 문턱 안(2,537문항에서 5문항). 최신 모델은 확신도 보정이 더 좋아 불확실 문항 선별 자체는 더 잘 됨 | **조건부**: 마지막 이틀에만, 검증셋에서 이득 확인 후 |

| **RAG·번역**(Osaka, LLM Science Exam) | 문서·지식 QA | 외부 지식이 필요 없는 과제 | **폐기** |
| **OCR 토큰 + 포인터 네트워크**(TextVQA 2019~2021, ST-VQA) | M4C·SMA·T5 계열 | VLM이 완전히 대체 | **폐기** |
| **fuzzy 문자열 매칭 후처리**(Mia 2021) | 생성 답변 보정 | 4지선다에선 보기와의 대조가 곧 채점이라 불필요. 단, 생성 브랜치(thinking)를 쓸 때는 생성문과 보기의 유사도 매칭이 필요 | **생성 브랜치 한정** |
| **합성 데이터·2단계 학습**(Benetech 2023) | pix2struct 계열 | 규정상 공개 데이터 허용 시 한글 간판 합성 데이터로 사전 적응 가능. 그러나 1주일 대회에서 합성 파이프라인 구축 비용이 큼 | **폐기**(시간 대비 이득 낮음) |
| **dev.csv 교육생 응답 다수결 준-라벨** | 1회차 34위(4/5 합의 902개), 15기 팀들 | 순위권 근거는 아님. 합의 기준이 엄격하면 학습 데이터가 18% 늘어나는 정도 | **조건부**: 2회차에 dev가 있고, 검증에서 이득이 확인될 때만 |

요약: **모델 세대가 바뀌어도 살아남는 것은 "확률 채점 + 파인튜닝 + 해상도 + 다른 계열 앙상블"** 네 가지이고, 이는 모두 2026년 8월 최신 모델에서 검증된 것입니다. **OCR 첨부·포인터 네트워크·RAG처럼 "모델이 못 읽던 시절"을 보완하던 기법은 지금 모델에서는 이득이 사라지거나 역효과**이므로 우선순위를 최하로 둡니다. 유일하게 텍스트 VQA 특성 때문에 재검증이 필요한 것은 "원본 이상 해상도"와 "층·위치 질문의 thinking 생성"입니다.
