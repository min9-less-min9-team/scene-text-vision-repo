# 논문 조사: 텍스트 이미지 4지선다 VQA에 유의미한 연구와 "아직 안 써본" 접근법

작성 2026-09-21. 대상: 이미지 속 (한국어) 글자를 읽어 4지선다에 답하는 과제. 기존 계획(`PLAN.md`, `DAY1_PLAN.md`)에 이미 들어간 기법은 "기존"으로, 들어가지 않은 것은 "신규"로 표시하고, 지금 모델(Qwen3.5/3.8, Qwen3-VL, InternVL3.5, 2026년 9월 기준)에서의 기대 효과와 비용을 판정했습니다.

판정 기준
- 근거 수치가 어느 세대 모델에서 나왔는지(LLaVA-1.5 시절 수치는 최신 모델에서 크게 줄어드는 경향이 반복 확인됨).
- 학습 필요 여부(1주일 대회, Colab Pro 1개 + 5070 Ti 4대).
- 우리 과제의 병목(작은 글자, 인접 간판 혼동, 층·위치 2단계 추론, 근사 문자열 보기, 텍스트 사전확률)에 닿는가.

## 1. 작은 글자·대상 영역 판독: zoom-in 계열

| 논문 | 방법 | 근거 수치 | 지금 모델에서의 기대 | 판정 |
|---|---|---|---|---|
| **ViCrop** "MLLMs Know Where to Look" (ICLR 2025, arXiv 2502.17422) | 학습 없이 모델의 attention/gradient 맵으로 답과 관련된 영역을 찾아 crop한 뒤 원본과 함께 재입력 | LLaVA-1.5 TextVQA 47.8→56.1(+8.3), InstructBLIP +12.2. **고해상도 LLaVA-NeXT에서는 +3.5로 축소.** 관계·개수 질문엔 효과 없음(한 영역만 봄) | 동적 해상도 모델에선 이득이 더 줄 것. 다만 "모델이 틀려도 어디를 봐야 하는지는 안다"는 관찰은 우리 병목(인접 간판 혼동)에 그대로 해당 | **신규·조건부**. 27B에서 attention 맵 추출은 메모리 부담. 9B에서 불확실 문항만 |
| **TextCoT** (2024, ACM TOMM, arXiv 2404.09797) | 3단계: 한 문장 캡션 → 모델에게 답 영역 bbox를 물어 crop(정사각·1.5배 확장·최소 448px) → 캡션을 맥락으로 붙여 crop으로 답 | LLaVA-1.5-13B TextVQA +8.5, Qwen-VL-Chat +2.2(DocVQA는 −2.3). 고해상도 모델 미검증 | Qwen3.5는 grounding(bbox 출력)이 강해 "대상 간판 bbox → crop → 재채점" 2-pass가 값싸게 구현됨. 기존 계획의 기하 crop(상단/하단/5분할)보다 질문 조건에 맞는 영역을 잡는다는 점이 다름 | **신규·추천(소규모 검증 후)**. 비용 2~3 forward |
| **ZoomEye** (2024-11, arXiv 2411.16044) | 이미지를 트리로 보고 존재 확신도·잠재 확신도로 하위 영역을 탐색 | LLaVA-ov-7B V* 75.4→90.6, HR-Bench 8K +10. Qwen2.5-VL-3B, InternVL2.5도 개선. 문서·구조화 레이아웃엔 부적합 | 초고해상도 자연 이미지용. 간판 사진(대개 1~4MP)에는 과함. 휴리스틱 다수 | **폐기**(비용 대비) |
| **HiDe** (2025-10, arXiv 2510.00054) | zoom-in이 도움이 되는 진짜 이유는 해상도가 아니라 **배경 간섭**이라 주장. 질문 토큰 attention으로 핵심 영역을 분리하고 레이아웃을 보존해 재구성 | Qwen2.5-VL-7B V* 92.1, InternVL3-8B 91.6(SOTA), 메모리 75% 절감 | "주변 간판이 방해한다"는 우리 가설과 정확히 일치. 학습 불필요. 다만 V*류 객체 탐색 벤치마크 결과라 글자 판독으로의 전이는 미검증 | **신규·검토**. 코드 공개 여부·Qwen3.5 호환 확인 필요 |
| **DeepEyes** (2025-05), **Mini-o3** (2025-09), **PixelEyes** (2026-07) | zoom-in 도구 호출을 RL 또는 궤적 SFT로 학습시킨 "thinking with images" | DeepEyes: Qwen2.5-VL-7B V* +18.9. Mini-o3: 다회전 탐색. PixelEyes: 인식(세그멘테이션)과 추론 분리 | 학습이 필요하고(궤적 데이터 + RL), 1주일·우리 GPU로는 무리. 공개 가중치(DeepEyes-7B)는 2025년 7B급이라 Qwen3.5-27B 제로샷보다 나을 근거 없음 | **폐기**(이번 대회) |

정리: zoom-in 계열에서 실제로 쓸 수 있는 것은 **"모델에게 대상 영역 bbox를 묻고 crop해서 다시 채점"(TextCoT식)** 하나입니다. 최신 모델은 원본 해상도로 이미 대부분 읽으므로 전체가 아니라 **불확실 문항·층/위치 유형에만** 적용하고, 검증셋에서 2%p 이상 오를 때만 채택합니다.

## 2. 4지선다 위치 편향(selection bias)

| 논문 | 방법 | 근거 수치 | 지금 모델 | 판정 |
|---|---|---|---|---|
| **PriDe** "LLMs Are Not Robust Multiple Choice Selectors" (ICLR 2024, arXiv 2309.03882) | 관측 확률 = 보기 ID 사전확률 × 내용 확률로 분해. 테스트의 5%에만 순환 순열 4회를 돌려 사전확률을 추정하고 나머지 95%는 나누기만 함 | llama-2-chat-70B MMLU +2.7, ARC +3.9; gpt-3.5 +0.8~1.7. 전체 순열(×24) +4.9, 순환(×4) +4.1, PriDe(×1.15) +2.6. 편향은 모델 크기와 함께 일관되게 줄지 않음 | 2026년 감사 논문(아래)에서 최신 MLLM도 순서 뒤집힘 24~50%가 남아 있어 보정은 여전히 의미 있음. 기존 계획의 TTA4(×4)보다 **3.5배 싸게** 비슷한 보정을 얻는 방법 | **신규·추천**. 27B test 추론에서 TTA4 대신 PriDe(5% 샘플 ×4 + 나머지 ×1)로 Colab CU 절약, 불확실 문항만 TTA4 |
| "Same Evidence, Different Answer" 순서 민감도 감사 (2026-06, arXiv 2606.26079) | 18개 최신 MLLM의 보기 순서 뒤집힘률 측정 | 뒤집힘률 24~50%, 최고 모델도 13.4%. **능력이 올라도 사라지지 않음**. 프롬프트로는 해결 안 됨 | 셔플 학습·TTA·PriDe가 2026년에도 필요하다는 직접 근거 | 기존(TTA) 정당화 |

## 3. 테스트 타임 스케일링·디코딩 (2026년 논문 다수)

| 논문 | 핵심 결과 | 우리 과제에의 의미 | 판정 |
|---|---|---|---|
| **On Test-Time Scaling for VLMs** (2026-06, arXiv 2606.28864) | 9가지 TTS(CoT, self-consistency, self-refine, describe-answer 등)를 Qwen3-VL 2B~72B, InternVL3.5, Molmo2에 적용. **수학·논리에선 큰 이득**(Qwen3-VL-2B WeMath 35→64), **지각 과제(RealWorldQA, A-OKVQA, MMStar perception)에선 대부분 기준선 이하**. 300토큰 조기 종료가 1,024토큰보다 지각 정확도 높음. 이미지 attention은 초반에 강하고 생성이 길어질수록 약해짐 | 글자 읽기는 지각 과제 → CoT·self-consistency를 전체에 걸면 손해. 층·위치처럼 2단계 추론이 필요한 소수 유형에만, 짧은 토큰 예산으로 | 기존 판정(CoT 폐기) 강화 + **유형 한정 짧은 CoT는 신규 실험** |
| **ImageCLEF 2026 Visual MCQ 1위** "Test-Time Scaling for Small VLMs on Multilingual Visual MCQ" (2026-07, arXiv 2607.09438) | 시험지 스캔(text-in-image) 5지선다, 11개 언어. **가장 큰 이득은 모델 교체**(Qwen2.5-VL-7B → Qwen3.5-4B, +11.4~15.1pp, 제로샷). self-consistency N=8→16은 +0.15pp뿐, 토큰 예산 1k→2k가 +3.7pp. PRM 빔서치는 8.7배 비용에 −0.39pp. 답 글자를 안 내는 체인 9% → 표준 "Answer:" 큐 + 제한 디코딩 복구로 2% 미만. 해상도 상한 약 100만 픽셀(약 4k 비전 토큰). 최종 84.06%로 1위 | 2026년 영문권 MCQ 대회 우승도 결국 **최신 정책 모델 + 파싱 안정성**이 핵심. 검증기·PRM은 효과 없음. 생성 브랜치를 쓴다면 "Answer:" 큐와 제한 디코딩(우리 로짓 채점과 동일 원리)이 필수 | 기존 방향 강화. 생성 브랜치 설계 시 참고 |
| **Revisiting Greedy Decoding for VQA: A Calibration Perspective** (2026-04, arXiv 2604.23443) | VQA는 답 분포가 머리에 몰린 폐쇄형 과제라 **greedy가 샘플링·self-consistency보다 낫고**, 보정과 정확도의 관계를 이론화 | 로짓 채점(사실상 greedy의 확률 버전)이 옳은 기본값이라는 2026년 근거 | 기존 정당화 |
| **AVIS** (2026-06, arXiv 2606.11576) | 난이도 예측기로 문항별 롤아웃 수·비전 토큰 수를 적응적으로 배분 | "불확실 문항만 비싼 추론"이라는 우리 선택적 재추론 전략과 같은 사상. 학습된 난이도 예측기 대신 margin·entropy·TTA 일치율을 쓰는 것이 1회차 1위 방식 | 기존 정당화 |
| **Visual Contrastive Decoding, VCD** (CVPR 2024, arXiv 2311.16922) + 후속 (2024-12 분석, 2025 RVCD) | 원본 이미지 로짓에서 노이즈/무이미지 로짓을 빼 언어 사전확률 의존을 줄임 | 우리 데이터는 **이미지 없이도 0.57~0.60**이 나올 만큼 텍스트 사전확률이 큼. 4지선다 로짓 채점에 그대로 적용 가능: 이미지 없는 forward 1회(이미지 토큰이 없어 매우 쌈)를 추가해 `logit(image) − α·logit(no image)`로 채점, α는 검증으로 결정. 파인튜닝된 모델에선 효과가 줄 수 있음 | **신규·저비용 실험**. 5070 Ti에서 9B로 반나절이면 판정 가능 |

## 4. 파인튜닝 방식: SFT vs RL

| 논문 | 결과 | 판정 |
|---|---|---|
| **Visual-RFT** (ICCV 2025, arXiv 2503.01785) | GRPO + 검증 가능한 보상. few-shot 분류에서 SFT는 기준선 이하, RL은 +24~26pt | 수십~수백 장 few-shot 상황의 결과. 우리는 수천 장 라벨이 있어 SFT가 이미 강함 |
| **VLM-R1** (2025-04) | 추론형 grounding에서 RL 63.1 vs SFT 54.8, OOD 일반화 우수 | 추론·grounding 과제 중심 |
| **When Does RL Help (Medical) VLMs?** (2026-03, arXiv 2603.01301) | RL은 출력 분포를 **날카롭게** 할 뿐(Acc@1↑) 능력을 넓히지 않음. Pass@K가 이미 높을 때만 효과. SFT가 기반 | 4지선다 한 글자 답에서 GRPO는 사실상 "정답 글자 확률 올리기"라 choice-CE와 같은 신호. 추론 체인을 붙인 RL은 비용이 크고 지각 과제엔 불리(3절) |

판정: **RL 파인튜닝은 이번 대회에서 폐기.** 27B는 자원상 불가, 4B/9B는 SFT 대비 이득 근거가 약함.

|---|---|---|
| **A.X 4.0 VL Light (SKT, 8B)** | 한국 장면 텍스트 벤치마크 OutdoorKorean 97.3, K-DTCBench 90.0, 한국어 벤치마크 대부분에서 Qwen2.5-VL-7B 우위. 한국어 토큰 수 41% 적음 | **Apache 2.0** → 파인튜닝 가능. 2025년 모델이라 Qwen3.5-9B보다 약할 수 있으나 "다르게 틀릴" 가능성이 큼 |

| **Text-VQA Aug** (2025-11, arXiv 2511.02046) | OCR 스포팅 + ROI 검출 + 캡션 + 질문 생성을 파이프라인으로 묶어 44K 이미지에서 72K QA 자동 합성·검증 | 라벨 없는 간판 이미지(예: AI Hub 야외 한글 이미지, 규정 허용 시)로 대회 형식의 QA를 만들 수 있음. 그러나 오답 보기 생성·검증 파이프라인 구축에 이틀 이상 소요. **테스트 이미지에 적용하는 것은 규정상 위험(테스트 데이터 활용 금지 해석)** |

| EXAMS-V 증강 (2025-09) | 이미지-텍스트 쌍을 하나의 이미지로 합성 | 시험지용 |

판정: 1주일 대회에서는 **폐기**. 규정이 외부 공개 데이터를 허용하고 팀에 여유 인력이 있을 때만 AI Hub 간판 이미지 + 합성 QA를 이틀 안에 시도.

## 8. 그 밖에 검토했으나 제외
- LoRA 어댑터 병합(soup, TIES/DARE): 같은 계열 재학습이 앙상블에 기여 0이었다는 1회차 2위 결과상 병합도 이득이 없을 가능성이 큼. 폐기.
- Set-of-Mark 시각 프롬프트(2023): 텍스트 영역에 번호 마크를 얹어 "3층 간판"을 지시하는 아이디어. GPT-4V 시절 8~15% 향상 보고. 최신 모델은 자체 grounding이 좋아 TextCoT식 bbox crop이 더 단순함. 보류.
- Zoom/RL "thinking with images"(DeepEyes, Mini-o3, PixelEyes): 학습 필요. 폐기.

| 1 | **한국어 특화 VLM(A.X 4.0 VL Light)을 앙상블 멤버로** | 1회차 2위 다양성 원칙 + SKT 모델 카드 | 계열 다양성 +0.3~1%p(2위의 이계열 +26문항 사례) | 5070 Ti 1대, 제로샷 게이트 1시간, QLoRA 4~6시간 | 불일치 ≥ 8%, 정확도 −1%p 이내 |

## 10. 결론

- 2024~2026년 논문들은 1회차 1·2위의 골격(확률 채점·파인튜닝·해상도·이계열 앙상블)을 뒤집지 않고 오히려 정당화합니다. 2026년 영문권 MCQ 대회 우승(ImageCLEF 2026)도 "최신 정책 모델 + 파싱 안정성"이 거의 전부였습니다.
- 정말 새로운 것은 네 가지입니다: **한국어 특화 VLM 멤버, PriDe식 저비용 편향 보정, 모델 grounding 기반 대상 crop, 무이미지 대조 채점.** 모두 학습이 필요 없거나 PC 한 대에서 반나절이면 판정됩니다.
- OCR 힌트는 한국어 장면 텍스트에서 효과가 없다는 직접 근거(2025-10)가 나왔으므로 시간을 쓰지 않습니다.

### 확인하지 못한 것
- PriDe·ViCrop·VCD의 수치는 2023~2025년 모델 기준이며 Qwen3.5-27B에서 직접 측정된 결과는 없습니다. 위 "채택 조건"은 그래서 검증셋 수치로만 판단하도록 잡았습니다.
- KOFFVQA 리더보드의 현재 순위(동적 페이지)와 HyperCLOVAX-SEED-Think-32B의 비전 지원 여부는 접속 실패로 확인하지 못했습니다.
- HiDe의 텍스트 벤치마크 결과와 공개 코드 상태는 초록 수준만 확인했습니다.
